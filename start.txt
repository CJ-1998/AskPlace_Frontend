# 의존성 라이브러리 설치
npm install

# 개발 서버 실행
npm run dev

# Vercel CLI 설치 및 로그인
npm i -g vercel
vercel login

# vercel.json 설정
{
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "/index.html"
    }
  ]
}

# 배포 
vercel --prod

# build 관련
package.json -> scripts -> build 
"vue-tsc -b && vite build" -> "vite build"
앞의 값은 오류 검사 빡세게 함
오류 다 고치면 앞의 것으로 수정 필요
